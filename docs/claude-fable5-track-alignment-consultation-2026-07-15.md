# Claude Fable 5: Fuji走行ライン位置合わせの相談結果

- 記録日: 2026-07-15
- 使用モデル: `claude-fable-5`
- 推論強度: `xhigh`
- 目的: 実車オンボード映像とCGリプレイの走行ラインを、ログ軌跡を不当に変形せずに一致させる方法を検討する
- ステータス: 一時保存

## 結論

- 現在の最適化処理自体は正常と判断された。
- `X=-10.45 / Z=+0.55`は、全周路面内率が`91%`から`63%`へ悪化するため棄却すべきである。
- `X=-3.5 / Z=-4.4`は暫定値として維持できるが、正解とはまだ確定できない。
- 現在の不整合はログ軌跡そのものより、A/B/Cの時刻、比較対象の境界、仮置きした目標gap `0.10m`に起因する可能性が高い。

- RMSE: `0.00m`
- condition: `3.20`
- 全周路面内率: `91%`

この結果から、ソルバーではなく入力した教師値または比較境界を先に疑うべきと判断された。

## 原因の優先順位

1. 衝突メッシュ端と、動画上の縁石・白線が一致していない
2. 動画とログの時間同期、またはA/B/Cの地点指定がずれている
3. MOD全体の世界座標登録に微小な回転誤差がある
4. GPSアンテナ位置とCG車両中心が異なる
5. heading、周回距離、座標投影に誤差がある
6. GPSの絶対誤差またはマルチパスがある

A地点は走行可能メッシュ幅が`21.5m`で、B/Cの約`15.3m`より広い。ピット側エプロンなどを連続した走行可能メッシュとして拾い、動画で見ている縁石とは異なる境界まで測っている可能性が高い。

## 次に行う単一実験: アンカー監査

### 1. 動画とログの時刻同期

- ログ上のブレーキ圧立ち上がりを抽出する。
- 動画上の減速開始、ノーズダイブなど、対応する現象を指定する。
- 最低2地点で照合し、全体に共通する時間offsetを求める。
- 目標同期誤差は`±0.05秒以内`とする。

高速区間では`0.1秒`の時刻誤差でも車両が数m進むため、位置補正より先に時刻同期を確定する。

### 2. 比較境界の分離

A/B/Cの各地点で、次の境界を別々に扱う。

- 連続した走行可能な衝突メッシュの端
- アスファルトと縁石の境界
- 白線
- 縁石の外端
- 左右タイヤの外端

現在の診断値は車体外形から衝突メッシュ端までの距離であり、タイヤから縁石までの距離ではない。この意味の違いを解消する必要がある。

### 3. 地点別の目標gap作成

動画を基に、A/B/Cそれぞれのタイヤ外端と対象境界の距離を設定する。すべてを一律`0.10m`とはしない。

厳密な画像計測が難しい段階では、次の区分を暫定的に利用できる。

| 判定 | gap目安 |
|---|---:|
| 接触または通過 | 0.0〜0.1m |
| ほぼ接触 | 0.1〜0.3m |
| 少し離れている | 0.3〜0.7m |
| 明確に離れている | 0.7m以上 |

### 4. 平行移動の再計算

同期済みの時刻、正しい比較境界、地点別の目標gapを使い、全地点に共通する`X/Z`平行移動を再計算する。

## 合格基準

- RMSE `< 0.3m`
- condition `< 10`
- 全周路面内率 `>= 91%`
- 特定地点だけ逆方向の`1m以上`の残差が残らない

この条件を満たせば、平行移動だけで説明可能と判断する。

修正後もAとB/Cで逆方向の残差が`1m以上`残る場合は、平行移動だけでは不十分と判断し、次に平行移動と微小な剛体回転を同時に検証する。

## パラメータの識別可能性

| 補正モデル | 変数数 | 3個のgapでの判断 |
|---|---:|---|
| 世界座標X/Z平行移動 | 2 | 推定可能。ただし教師値の正確性が必要 |
| 車体座標レバーアーム | 2 | headingの異なる地点があれば限定的に推定可能 |
| 平行移動 + レバーアーム | 4 | 推定不能。最低4〜6地点以上が必要 |
| 平行移動 + 微小回転 | 3 | 数学的には解けるが余剰観測がなく、3地点では信頼できない |
| 時間offset | 1 | gapから解かず、ブレーキなどのイベント相関から求めるべき |

## GPSアンテナと車体中心

GPSアンテナ位置からCG車両中心への変換は、ログ軌跡のワープではなく正当な座標原点変換である。

ただし一般的なレバーアームは`1.5m程度以下`と考えられ、現在の`6〜10m`級の不整合を単独では説明できない。平行移動と同時に推定する場合は、向きの異なる4〜6地点以上、または実測したアンテナ搭載位置が必要になる。

## 衛星画像の役割

衛星画像は車両軌跡を直接フィットするためではなく、MOD全体の世界座標上の配置を確認するために使う。

- MODの白線や縁石と衛星画像上の線形物を比較する。
- MOD全体の静的な平行移動と微小回転を検査する。
- 精度目安は約`0.5m`とする。
- タイヤと縁石の数十cm単位の判定には使用しない。
- 自動最適化の目的関数には直ちに組み込まず、独立した検証材料として扱う。

## 避けるべき補正

- ログ軌跡の地点別または区間別ワープ
- スプラインによる手動変形
- 道路端への自動吸着
- 時間変化する平行移動
- 軌跡全体の根拠のないスケーリング
- 未確認の`0.10m`教師値の強制
- 棄却済みの`X=-10.45 / Z=+0.55`の適用
- 根拠のない大きなMap rotation
- レーザースキャンメッシュの非剛体変形

## 当面の方針

新しい補正モデルを追加する前に、動画同期と比較境界を正しく定義し、A/B/Cの教師値を作り直す。その後、平行移動だけで合格基準を満たせるかを再検証する。
