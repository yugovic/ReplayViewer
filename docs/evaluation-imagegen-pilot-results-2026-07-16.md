# ImageGen 12枚パイロット 結果評価（Replay比較接続・向き検証込み）

- 記録日: 2026-07-16
- 成果物: ユーザーが手動生成した12枚（1254×1254、`imagegen_trials/pilot/成果物/`）
- 手順書: [guide-imagegen-pilot-2026-07-16.md](guide-imagegen-pilot-2026-07-16.md)
- 関連: [evaluation-imagegen-fidelity-2026-07-16.md](evaluation-imagegen-fidelity-2026-07-16.md)（前回フリー生成の失敗計測）

## 結論

1. **忠実度ゲートは素の状態で0/12 PASS**だが、前回フリー生成から大幅良化。
   失敗主因は色ずれ（生成側の再グレーディング）で、**決定論的な色補正後は
   ほぼ解消**（Δ色0.8〜1.4）。幾何は11/12がシフトゲート内。
2. **知覚品質は現行ベスト（静岡20cm SR）を全12地点で上回る**
   （MUSIQ +2.3〜+15.0、MANIQA全勝）。
3. **「向きがおかしい」は画像・表示の両レベルで検出されず**（全数照合済み）。
   知覚要因（描き直された影・芝目の方向矛盾）の可能性が高い。
4. 12枚は色補正+縁フェザー済みタイルとしてReplayに表示接続済み（可逆）。

## 3. 「向きがおかしい」の検証結果

3レベルで全数照合し、**幾何学的な誤りは検出されなかった**。

1. **画像レベル**（12/12枚）: 各生成画像をソースと8方位（回転4×鏡映2）で
   NCC照合 → 全枚が正方向で最良（NCC 0.994〜0.998）。取り違え・回転・鏡映なし。
2. **表示レベル**（4地点サンプル: #01/#04/#09/#10）: Replay実画面を真上・北=上で
   撮影しソースと8方位照合 → 全て正方向が最良。
3. 表示経路は標準SRタイルと同一コード（同じUV規約・flipY）であり、
   タイル毎に向きが変わる余地は構造上ない。

もっともらしい知覚要因: 生成AIが影・芝目・スキッド痕の**方向性のある質感を
描き直している**ため、周囲と方向が矛盾して「回転して見える」ことがある
（LR一貫性20〜27dBの描き直し分）。特定のタイルで顕著な場合は番号の指摘が
あれば個別に精査する。

## 4. Replay表示（接続済み・可逆）

- `imagegen_trials/manifest.json` をパイロット12枚構成へ差し替え
  （priority 10、24px縁フェザー、provenance記録付き）。
  `?sat=shizuoka_x2`・Google OFF で標準SRタイルの上に表示される。
- **追記（同日23時）: レイヤーパネルに「Trial tiles」トグル（キー `I`）を実装**。
  同じ視点のまま ON=生成タイル / OFF=現行の静岡20cm SR を瞬時に切替でき、
  in-place A/B 比較ができる（OFF中は該当タイルのフェッチも停止）。
  実画面検証: 表示中オーバーライドメッシュ ON=1→OFF=0→再ON=3、エラー0。
- 実画面検証: 総タイル152=標準140+パイロット12認識、HTTP 200、エラー0。
- **復元**: `manifest.pre-pilot.json` を `manifest.json` へ上書きコピー→リロード
  （トグルで足りる場合は不要）。

## 5. 次の判断材料

- 生成編集は「鮮鋭度で現行SRを明確に上回るが、細部を描き直す」ことが確定。
- 採用パターン候補: ①コース外（#10-12）から採用 ②on-trackはベクトル線・縁石
  レイヤーが位置の真実を担保している前提で「見た目レイヤー」として限定採用
  ③不採用（SR+コア4×リングで代替）。いずれもユーザーの実機目視で判断。
- 自動化する場合はAPI従量（12枚$0.5〜3規模）。プロンプト・ゲートは本パイロットの
  ものを流用可能。
