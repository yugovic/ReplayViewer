# 富士：クリッピングポイントでの縁石との関係（KPIの見直しと原因の切り分け）第3版

## 要旨

**KPIを「コース外にはみ出した時間」から「クリッピングポイントで内側タイヤが縁石とどういう関係にあるか」に改め、ずれの原因を切り分けた。** Sonnet 5.5とFable 5.1に2回ずつレビューさせ、指摘に沿って主張を撤回・修正し、追加の試験を行った（第3版）。

**結論**

1. **コース側に、直すべき誤りがある（確度が高い）。**
   - (a) 縁石の路面側には幅約0.4mの白帯（トラックリミット線）がある。CGの縁石は外側の赤白ブロックから始まっているので、白帯を基準にした見た目やトラックリミットの判断では、約0.4m外側にずれる。
   - (b) 縁石15・23は約1.0m（最大1.84m）の引き誤り。縁石の端にも誤りがある。
   - (c) ダンロップ右（2965〜3004m）の縁石がCGに無い。赤白ブロックが写っている通常の縁石で、7/30の全周がここを使っている。
2. **GPS側には、周や場所で変わる横方向のずれが残る（確度は中程度）。**
   - セッションごとの大きな偏り（両日で約4.7m差）は平行移動で取れる。
   - それとは別に、7/30 L2では周の中で1〜2m以上の、場所によって変わるずれがある。証拠は3つある。
     - 3580〜3600mの強い振動：同じ表示位置を通ったL3では出ていない。
     - ステアを戻す時刻：GPS上の動きより0.3秒遅い。
     - 縁石21と縁石24に、符号が逆の矛盾が残る。
   - 平均的な誤差の大きさは、ラベルからは±0.4〜0.7m程度としか言えない。
3. **補正の決め方が、クリッピングポイントの絶対位置を決められていない（確度が高い）。**
   - 道路境界だけを使う現行の推定は、南北方向に0.5〜1mの「どこでもよい」平らな領域がある。どこに止まるかは探索の始め方で変わる。
   - IMUの縁石接触ラベルを加えると、補正は1点に定まる。
     - 不感帯を4通り変えても0.13m以内しか動かない。
     - アンテナ位置の推定値は右−0.02m・前+0.04mで、ほぼ車体の中心。
   - ただし改善幅は統計的に限定的である（下記）。

**撤回した主張**
- 第1版：
  - 循環した検証を根拠にした点
  - L5の0.59mドリフト
  - 向きの変化率の一致を横位置の証拠にした点
  - 白帯の二重計上
- 第2版：
  - 「ダンロップ右は平らな塗装域で振動しない」
  - 「車輪速度の揺れで左右を判定できた」（コーナーの向きとの交絡）
  - 「縁石区間の道路幅の誤差が補正を0.8m偏らせた」（実際は平らな領域の影響）
  - 「回転・縮尺の歪みはない」（正しくは「ラベルからは判定できない」）

**対策と、レビュー2回を経た可否**

| 対策 | 判定 | 条件 |
|---|---|---|
| コースの縁石区分（白帯／ブロック／外側の端）、縁石15・23と端の修正、ダンロップ右の追加 | **進める** | 出典（CC BY 4.0、2019年画像で2020年とは未照合）を記録する。ダンロップ右のブロック開始は検出値に置き換える |

## KPIの定義

| 量 | 意味 |
|---|---|
| g_block（前輪・後輪） | 内側タイヤの外端と赤白ブロックの始まりとの符号付き最短距離。マイナスはブロックに乗った量 |
| g_paint（前輪・後輪） | 白帯の始まり（トラックリミットの線）との距離 |
| クリッピングポイントの位置 | g_block が最小になる地点（m）。周どうしで比べて早い・遅いを見る |
| ブロックに乗った長さ | 内側前輪がブロック上にあった距離 |
| 立ち上がりの外側 | 縁石の後120m以内で、外側タイヤと反対側の道路端との最小距離 |
| 接触（IMU） | 強い振動の有無・継続時間（GPS非依存）。左右は判定しない |

運転の指導では、同じコーナーでの**周どうしの差**を主に使う。共通のGPSのずれが打ち消されるためである。絶対値は幅つきで示す。

## 正解の基準：IMUの縁石接触

- **データ：** 原XRKの50Hz IMUと4輪の車輪速度。ラップの時刻とはGPS速度で対応づけた（誤差0.0003km/h）。7/30はロガー時計を+0.507秒ずらした。
- **検出：** ロールレートの高周波成分（0.2秒窓の実効値）が1.0を超えた区間を一つの出来事とする（0.3秒未満の切れ目はつなぐ）。内側縁石の通過で、ピークが1.5以上なら「強い接触」、0.8以下なら「接触なし」とする。
- **左右判定の撤回：** 振動のないコーナリング中でも、車輪速度の揺れの左右比は右コーナーで0.82、左コーナーで1.31、直線で0.99だった（7/30）。内側の車輪ほど揺れが大きいため、左右判定はコーナーの向きと区別できない。内側縁石のラベルは「内側の車輪が当たった」とみなして使う。
- **限界：**
  - 強さは速度や標本化（エイリアシング）に依存する。
  - ブレーキのロックや段差など、縁石以外の振動を除外していない。
  - しきい値は7/30のデータで決めている。
  - 7/29は強い接触が1件しかない。

## 結果1：補正の方式ごとの比較（7/30、外したラベル58件）

| 方式 | 矛盾（±0.15mの許容） | AUC |
|---|---|---|
| 元GPS | 11件 | 0.898 |
| 現行の配信値（道路境界のみ・周ごと） | 3件 | 0.878 |
| 道路境界のみのセッション推定 | 8件 | 0.874 |
| 道路境界＋他の縁石の接触ラベル（縁石を1つずつ外す交差検証） | 2件 | 0.933 |

- **統計的な評価（Sonnetの再計算）：**
  - 現行の配信値との差（3件→2件）は有意ではない。
  - 道路境界のみの推定との差は、縁石単位のブートストラップで矛盾数の差の95%信頼区間が［−12, 0］、AUCの差が［+0.001, +0.15］で、ぎりぎりの改善にとどまる。
  - 同じ縁石の中での順位の当たりは0.889→0.907（27組）。
- **許容幅の感度：** 0.15mで2件、0.10mで4件、0mで5件。
- **残る2件：** L2の縁石21（3288m、強い接触なのに+0.83m）と縁石24（3852m、振動なしなのに−0.99m）。符号が逆なので、L2の周内で場所によって変わる誤差である。
- **道路境界だけの推定：** 南北方向に平らな領域があり、（+0.41, −2.87）にも（+0.49, −3.47）にも止まる。欠落していた塗装域を加えても、ラベル込みの推定（+0.51, −2.18）には近づかなかった。
- **回転・縮尺：** あてはめた値（−0.055°、+0.42‰）は中心から2kmで約1.9m・0.8mに相当し、誤差の規模と同程度である。矛盾の数（2→3件）では区別できないので、**判定不能**とした。

## コース側の検証

- **白帯：** 白帯の始まりは、CGの縁石の内側の線より0.32〜0.49m路面側にある（縁石15・23は約1.0m）。赤白ブロックの始まりはCGと±0.06m以内で一致する（15・23は+0.2m）。
- **欠落していた縁石：** CGの道路端の外側2.5m以内を赤の塗装で走査した。クリッピングポイントに関わる欠落はダンロップ右だけ。赤が連続して検出されたのは9.5mだが、写真では弧に沿って赤白ブロックが続き、走行では40mにわたって使われている。ブロックの始まりは仮定値（塗装の始まり＋0.42m）なので、検出値に置き換える必要がある。
- **誤差の見積もりに入っていない項目：** オルソ画像の位置合わせ誤差（約0.2〜0.3m）と、2019年画像と2020年の実際の差。

## 動画による距離測定（未完）

CGの線を動画に投影するカメラ校正は、焦点距離・高さ・ロールと横位置を区別しきれない。次の手順とする。

- 強く接触した瞬間のフレームで尺度を固定する
- 物理的な校正（チェッカーボード）と取付位置の実測を行う
- 2日分を共通のカメラ値で推定する
