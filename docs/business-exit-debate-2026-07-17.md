# 事業出口ディベート記録 — 3Dリプレイ資産の拡げ方とクローズ（2026-07-17）

4体のサブエージェント（事業拡大派 / 懐疑派リスク監査 / 日本モータースポーツ業界アナリスト / 出口戦略設計）による2ラウンドの討論と、モデレーター（Claude Fable 5）による統合判定。
テーマ: メーカー売却・レース事業者売却・権利全部売却・イベント連動提供を含む出口の具体形。
前提: [business-debate-2026-07-14.md](business-debate-2026-07-14.md)（条件付きYes 58%、スクール向けデブリーフ基盤、Go/Killゲート）を土台に、出口面を深掘りした続編。

## 要旨

- **出口の本命は「今すぐの権利全部売却」ではない**。プレレベニューの現在価値は50〜300万円（コード代）に過ぎず、売り急ぐ額ではない。価値が跳ねる唯一のレバーは**有償PoC 1件（50万円以上・書面）**で、これで売却価格レンジが2〜5倍になる。
- **拡げ方**: 権利者（サーキット・スクール・走行会主催者）を顧客にするB2B2C一本。この構図は商標・施設権利リスクを消滅させ、むしろ参入障壁に反転する。**OEN直販は取り下げ**（調達壁。GRスクール等の運営受託会社へのサブベンダー納品に吸収）。個人向け細売り(B2C)は両陣営一致で棄却。
- **閉じ方の最有力形**: Racing UnleashedによるvTelemetry PRO買収（2025-01、IP+キーパーソン承継）が直接コンプ。つまり現実の出口は**「IP+人」セットのacqui-hire型**か、**非独占ライセンス→独占オプション→買収のエスカレーション型**。プロダクト単体の値札は期待しない設計で交渉する。
- **生成AI高精細化レイヤー（imagegen_trials等）は売り物から除外**。AI自律生成部分は著作権が立たない恐れがあり、DDで減点要因。デモ用の表示レイヤー（OFF可能な構成）に格下げし、IP資産目録に入れない。逆に**権利チェーン台帳の規律そのものが「商品」**（競合MOD文化には作れない）。
- 懐疑派が提示した**5つの検証可能な撤回条件**（下記）を出口価値のゲートとして採用。全シナリオは「有償PoC 1件の従属変数」。

## 2. ラウンド1の対立点（要約）

**拡大派の5シナリオ（原案）**: ①施設向け「走行体験アフターサービス」SaaS（年100〜500万円/施設+参加者課金）②プロモーター向けファンエンゲージメント受託（SFgo月1,480円が支払意欲を実証、S耐/SUPER GTに3D俯瞰は空白）③OEMオーナー向け受託 ④コース3D生成パイプラインのライセンス販売（rFpro/OHW/Virtexが市場実在を実証、日本の自治体オープンLiDARは世界的に突出）⑤IP売却（Garmin/AiM系/Track Attack/GAZOO Racing Company等）。

**懐疑派の監査**: 個人課金層は数百人オーダー／AiM Race Studio 3無料とRaceChrono $20に挟撃／富士の名称・形状の無許諾商用化は警告状一通で停止／生成AIタイルに譲渡可能な権利が立たない恐れ／VIRTUAL SHIZUOKAは静岡限定でスケール停止／大企業調達は個人を機械的に落とす（PoC死）／売上ゼロのIPは数十万〜数百万円／イベント1人オペは破綻（30人×15分=7.5時間）。失敗シナリオ: 無許諾富士商用化・売却磨き込み1年の機会費用・イベント安請け合いの悪評一周。

## 3. ラウンド2で決着した点（両者合意）

| 論点 | 決着 |
|---|---|
| B2C細売り | **棄却**（両者一致。数百人市場に反証なし） |
| 生成AIタイルの権利 | **売り物から除外・デモレイヤー格下げ**（拡大派が譲歩。OFF可能な設計なら中核への権利批判は及ばない、と懐疑派も譲歩） |
| サーキット商標リスク | **権利者を顧客にする構図で消滅・障壁に反転**（懐疑派が譲歩。失敗シナリオ①はこの構図では成立しない） |
| 静岡限定論 | **技術限界ではなくデータ在庫の問題**（兵庫県全域・東京都・長崎県・栃木県等へ点群公開が拡大中）。ただし主要サーキット所在県の被覆・密度・鮮度は未検証で「静岡並みにいつでも」は未実証（拡大派も段階販売に修正） |
| 出口の実在 | **「出口ゼロ」は撤回**（懐疑派）。ただしvTelemetry PROは「IP+人」の承継であり、プロダクト単体に値が付く根拠にはならない（拡大派も磨き込みを3〜6ヶ月+並行営業に限定） |
| ライセンス台帳 | **DDで実効的な差別化＝商品**（懐疑派が明示的に認めた） |
| PoC | **無償PoC禁止・有償小額（10〜30万円のイベント支援受託から）**。全シナリオは有償PoC 1件の従属変数 |

**懐疑派の事実キャッチ（重要）**: TGRの富士プログラムは既に「TOYOTA GAZOO Racing Recorder」+専用Viewerで走行データ持ち帰り・プロ比較を内製済み。「TGRの空白を埋める」提案は成立せず、**標的はTGR的仕組みを持たない中小施設・スクール・走行会主催者**に絞る。

## 4. 残争点（市場接触でしか解けない）

- 施設側の支払意欲（Garmin $1,199を払うのは個人であり、施設の財布の証拠は未提出）
- 「実コース3D×Web×商用クリーン」の空席が「儲からないから空いている」のではないことの立証
- 静岡県外1コースの再現コスト・工数の実測
- プロモーター案件の調達経路（放送品質SLAの世界に個人がどう入るか — サブベンダー経由が唯一の現実解）

## 5. 統合判定（モデレーター）

### 拡げ方（優先順）

1. **中小施設・スクール・走行会主催者への有償スモールスタート**（1回10〜30万円のイベント支援受託 → 施設ライセンス化）。入口は富士圏の走行会主催者（Zummy等）・AiM正規代理店網（Star5/XTRA/ベア）・シミュレータ施設（TVC等）。2026-07-14討論の「スクール向けデブリーフ基盤」と完全整合。
2. **STMO（スーパー耐久）圏へのボトムアップ**: ジェントルマンチーム1〜2チーム→監督経由で事務局→富士24時間のファンゾーン/配信素材。財布は支援企業の協賛アクティベーション枠。直接提案ではなくSIer/スポンサーのサブベンダーとして。
3. **コースパイプラインの段階販売**: 静岡県外1コースを実測実証（総コスト100万円以下・工数台帳つき）してから県単位で商材化。
4. OEM直販はしない（運営受託会社への納品に吸収）。

### 閉じ方（出口設計）

- **推奨パス**: 非独占ライセンス（買収オプション条項入り）→ 独占化 or 事業譲渡 → 「IP+人」承継型売却。詳細は [design-exit-strategy-2026-07-17.md](design-exit-strategy-2026-07-17.md) の18ヶ月ロードマップ（G0〜G5）に従う。
- **売却価値の作り方**: ①権利チェーン台帳の証拠化（PROVENANCE.md+サイドカーJSON、費用ゼロ・最優先）②静岡県外の第2コース実証 ③有償PoC 1件 ④買い手ロングリスト10社（接触は実績後）。
- **タイミング**: 今の50〜300万円で売り急がない。2027-01-14の既存Go/Kill判定でKillなら粘らず即売却モード（Acquire.com/TRANBI出品+10社直接打診、acqui-hire打診は所得として受ける）。
- **OSS化は封印**（IP売却価値を不可逆にゼロ化するため最終手段）。

### やってはいけないこと（失敗シナリオの残存分）

- 富士の名称・形状を前面に出した無許諾の有料B2Cサービス（権利者が顧客になる前に始めない）
- 無償PoC（知見だけ吸われて内製化されるPoC死）
- 手作業前提のイベント当日オペ（形式をAiM系に限定・事前アップロード制にしてから受ける）
- 生成AIタイルをIP資産目録・売り物に入れること

## 6. 出口価値ゲート（懐疑派の撤回条件を採用）

1. 有償PoC 1件: 50万円以上の書面契約を12か月以内（無償不可）
2. 静岡県外1コース再現: 総コスト100万円以下・精度検証記録・工数台帳つき
3. 脱属人化: 30名規模イベントで開発者以外が手順書のみで当日納品成功率90%以上
4. 権利チェーンの第三者確認: 弁護士/弁理士レビュー済み台帳+生成AIレイヤー完全OFF構成での全機能動作
5. 買い手の需要シグナル: Garmin/AiM系/Track Attack/GAZOO Racing Company等からの書面関心表明またはLOI 1件

条件1+3で「事業」へ格上げ、条件5で「売却シナリオ」が現実化。2026-07-14のGo/Killゲート（08-14接触25/09-30入金1/11-14有料パイロット3/2027-01-14最終判定）と並走させる。
