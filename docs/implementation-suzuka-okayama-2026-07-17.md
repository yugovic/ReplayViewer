# 鈴鹿・岡山国際のトラックデータ作成（プレイブック初適用）

- 記録日: 2026-07-17
- 依頼: 「鈴鹿サーキット、岡山国際サーキットを対象にデータ作成。必要に応じて
  subagentで並行作業」
- 適用手順: [guide-circuit-imagery-playbook-2026-07-17.md](guide-circuit-imagery-playbook-2026-07-17.md)（Step 0〜6）

## 要旨

プレイブックを初めて富士以外へ適用し、**鈴鹿・岡山国際の2トラックを同日で
Replay表示可能な状態まで構築**した。画像ソースはOpus subagent 2体の並行調査で
「国土地理院シームレス写真 z18（約0.49m/px）」に確定 — e-Gov一次情報で
**政府標準利用規約2.0（CC BY 4.0互換）＝加工・商用・同梱可・承認不要**を確認済み。
中心線はOSM（ODbL）から新規スクリプトで組み立て（鈴鹿は40ウェイ結合で公式
5,807mに対し誤差0.1%、標高は地理院DEMから付与）、グレーディング→SR
（知覚ゲート一発通過、LPIPS −60〜69%）→合成プレビュー走行まで一気通貫。
制約は元GSDが0.49m級であること（富士20cmの約1/2.4）と、中心線が測量値でない
こと（OSM精度1〜5m、可視化用）。

## 2. 作ったもの

新規パイプライン（汎用・再利用可）:

- `pipeline/fetch_gsi_ortho.py` — bbox→GSIタイル取得→EPSG:3857モザイク+meta
- `pipeline/bootstrap_track_from_osm.py` — OSM racewayウェイ群から閉ループを
  組み立て（直進優先ウォーク+名前除外+公式長ゲート）、地理院DEM(dem5a/5b/dem)で
  標高付与、7m間隔リサンプル、track.json生成（provenance=ODbL/可視化用と明記）
- `pipeline/make_preview_race.py` — 中心線を定速走行する**合成プレビュー
  ラップ**（メタ全項目にSYNTHETIC明記）。実ログ到着前のコース/画像確認用

## 4. 制約と次の一手

- **画質**: 元GSD 0.49m（富士20cmの約1/2.4）。近景は富士より明確に甘い。
  SR+グレーディング+近接ディテールは適用済みで、これがGSIソースの上限。
- **中心線は測量値ではない**（OSM由来1〜5m精度・カント無し・幅は概算12m）。
  実テレメトリ到着時にfuji同様の手修正エッジ整備が必要。
- 次の一手（優先順）:
  1. 岡山: おかやまインフラボックスのLPオルソ2024メッシュ照合（CC BY 4.0、
     該当すれば0.2m級が無償で入る）
  2. 鈴鹿: 実ログ運用が決まったら15cm購入+承認（数千円+手続き）
  3. 実テレメトリでの走行確認と、track幅・S/F位置の微調整

## 追記（2026-07-18）: 両トラックの品質アップグレード完了（Opus subagent×2並行実装）

- **岡山 → i-boxオルソへ全面置換**: 上記「次の一手1」を実施。i-boxの
  メッシュ索引API発見と国土基本図図郭コード解読により**6メッシュで被覆100%**を
  確認し、**0.25m/px（GSI比約2倍）・2024年計測・CC BY 4.0**で置換。ベース
  5014×7521、SRコリドー60タイル（強度0.85、LR 35.4dB・シフト0.135px、
  ゲート全通過、SR格子0.125m/px）。新規 `pipeline/fetch_ibox_ortho.py`。
  旧GSI版は pipeline/cache/gsi_okayama/ に温存。
- **鈴鹿 → 画像処理で改善**: グレーディング再調整4候補とSR前unsharpは計測で
  非改善（既定グレードが最良）につき不採用。採用は**SR出力格子のx2→x4化**
  （0.123m/px・2048pxタイル32枚・ガード通過最大強度0.45）。実利用の画面表示
  サイズで**MUSIQ 32.7→42.2（+29%）**、LR 34.4dB・シフト0.309pxで全ゲート
  PASS。パイプラインへ `--output-scale` / `--pre-sharpen-*` / グレードCLI
  パラメータをadditive追加（fuji/okayama既定挙動は不変）。情報解像度は
  0.49mのまま（表示格子の高精細化）で、真の向上は有償15cmルートのみ。
- 統合検証: 全304テスト+python unittest 20件+本番ビルドPASS、Playwright
  実画面で両トラックの表示・帰属クレジット・consoleエラー0を確認。
