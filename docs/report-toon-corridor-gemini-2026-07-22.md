# トゥーンコリドー実装レポート — Gemini 採用で全周完成（2026-07-22）

## 要旨

富士の走行路面±51mのコリドー全周（4.6km・59窓）を Gemini
`gemini-3.1-flash-image` でセル画調に変換し、Replay 表示まで完成させた。
Stability AI は2方式とも位置忠実度で不合格、**Gemini 編集モデルのみが
「画風変換しつつ地物を1px単位で保持」を達成**（エッジ重なり率0.91〜1.00、
全体シフト≤0.4px@512）。つなぎ目の黒帯はオフライン合成→不透明タイル化で解消、
濃緑の芝・路面上の影・車両は対象窓の再生成で除去、芝色は実測値
`#BCCF25` の決め打ち指示が有効と実証。総コスト約$10。
残課題は 006/007 の色ドリフト、パレットスナップ後処理による色統一の恒久化、
低スコア2窓の精査、路面ロゴの実在/幻覚仕分け、コース外遠景の扱い。

## 1. 経緯（1日の意思決定ログ）

| 段階 | 結果 |
|------|------|
| ロジックベース3方式（シェーダ/K-means/ルールベース） | 品質不足で断念・全ロールバック（前日） |
| Stability Structure Control | **不合格** — 構造が全壊し別の場所を創作 |
| Stability Style Transfer（12地点×3設定） | **不合格** — 画風は良いが白線・ランオフ等のジオメトリが描き替わる |
| **Gemini 3.1-flash-image（12地点パイロット）** | **合格** — シフト≤0.4px、重なり率91〜100%。ロゴ・縁石・森を保持 |
| Gemini 全周コリドー59窓 | 全成功（再試行8回）。黒帯対策・クリーン化を経て**適用中** |

flash-lite（1/3価格）も3枚比較: 2枚は互角だが1枚で色ブロブ幻覚 → 本命は
3.1-flash、lite は不採用。

## 2. パイプライン構成（pipeline/gemini_toon_corridor.py）

1. **prepare**: 中心線に沿い 76.8m 間隔で 512px（102.4m四方）窓を59個切り出し
   （native 0.2m/px グレーディング済みモザイク、128px オーバーラップ）。
2. **run**: 各窓を Gemini へ（src + ロゴ除去済みスタイル参照
   `ai_illustrated_tile_nologo.png` + 地物固定プロンプト、temperature 0）。
   エッジ重なり率<0.90 は自動再試行し良い方を採用。全呼び出しを
   run_log.json に記録。
3. **stitch**: 59窓をオフラインで1枚に合成（トゥーン同士でクロスフェード）
   → 重なりのない**不透明** 1024px グリッド91枚に切り直し
   → imagegen_trials/manifest.json（トライアルタイル機構）で表示。

重要な教訓: **ランタイムの半透明フェザーは禁物**。下の写真地面が透けて
つなぎ目に黒帯が出る。ブレンドは必ずオフラインで済ませ、実行時タイルは
不透明にする。

## 3. 品質向上の実証結果

- **幻覚対策**: スタイル参照に写るロゴが全タイルへ転写される
  → 参照からロゴ部を切除して解消。路面の架空ロゴは禁止文の明示で解消。
- **クリーン化**（ユーザー決定: 黄緑維持/車除去は走行路面上のみ/影も路面上のみ）:
  該当17窓を追加規則つきで再生成、全て重なり率0.94〜1.00で成功。
- **色の決め打ちが有効**: 相対指定（「image 2 と同じ黄緑」）はドリフトする
  （006/007 がマスタード化）。既存の良好窓から実測した
  **`#BCCF25` を16進で指定**した窓005は周囲と完全に一致。
- 前後比較ページ: `toon_corridor/compare.html`（実画面前後 + 修正19窓の前後表）。

## 6. 残課題（優先度順）

1. **006/007 のマスタード色ドリフト** — `#BCCF25` 決め打ちで再生成（約¥20）。
2. **パレットスナップ後処理** — stitch に「芝→#BCCF25 / 路面→基準グレー」の
   写像を追加すれば以後の色統一が数学的に保証される（API費用ゼロ、最優先推奨）。
3. **低スコア窓の精査** — corridor_024（0.79）/ 021（0.87）は初回生成のまま
   目視未確認。
4. **路面ロゴの仕分け** — 「GR」「F1」風マークの実在/幻覚を元写真と突き合わせ
   （富士は実在の路面ペイントがあるため機械判定不可）。
5. **コース外遠景** — 俯瞰では「コースだけイラスト」。演出として許容するか、
   全面展開（+約$8）するか。
6. **トゥーン表示のワンタッチ化** — プリセット or URLパラメータ。
7. **鈴鹿・岡山への横展開** — 同パイプラインがそのまま使える見込み。
