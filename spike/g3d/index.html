Google Maps Platform API キーを入力

Photorealistic 3D Tiles を表示するには「Map Tiles API」を有効にした API キーが必要です。キーは localStorage にのみ保存され、 コードには一切含まれません。URL に ?key=... を付けても可。

キー未取得の場合はこのまま閉じられません。取得後にこの画面から入力してください。
