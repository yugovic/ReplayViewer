# はじめてでもできる — 富士のコースを Blender で仕上げる完全ガイド

**やること（全体像）**: 正確な部分（コースの形・高さ）はすでに自動で用意してあります。
あなたがやるのは **「道幅を衛星写真に合わせる」「縁石と白線を足す」「書き出す」** の3つだけ。
高さは LiDAR（レーザー測量）で正しいので、**上下方向は一切さわりません**。

```
【済】地形(LiDAR) + コースの線(ロガー) ──▶ あなた: 幅あわせ → 縁石 → 書き出し ──▶ ビューアで走る
```

- 所要時間の目安: 初回 60〜90分（慣れれば30分）
- 使うソフト: Blender 5.1（インストール済み）＋ Track Tools（購入・設置済み）
- **保存はこまめに**: `Ctrl+S`。最初に好きな場所へ `fuji_build.blend` として保存してください。

---

## 0. Blenderの操作は3つだけ覚えれば大丈夫

| したいこと | 操作 |
|---|---|
| 視点をまわす | **マウス中ボタン（ホイール）を押しながらドラッグ** |
| ズーム | **ホイールを回す** |
| 真上から見る | **テンキーの 7**（テンキーが無いPC: 画面左上メニュー `View > Viewpoint > Top`） |

もう1つ: 画面の右上にある**球のアイコンが4つ並んだところ**は「表示モード」です。
並びは「①ワイヤーフレーム ②ソリッド ③マテリアルプレビュー ④レンダー」。
**左から3番目（マテリアルプレビュー）**を押すと、色や写真が見えるようになります。
迷ったら: 3Dビュー内にマウスを置いて `Z`キー → 出てきたメニューで `Material Preview` を選択。

> ⚠️ **超重要（このガイドで一番ハマりやすい所）**
> **②ソリッドモードでは、写真やテクスチャは仕組み上ぜったいに表示されません**（Blenderの仕様）。
> 色についてもソリッドモードは「表示専用の近似色」という別設定を見るため、
> それを設定し忘れると**全部同じ薄灰色**に見えます（このキットのスクリプトは対策済みですが、
> 写真・市松模様の縁石だけはソリッドモードでは原理的に無理です）。
> **→ 作業中は基本ずっと③マテリアルプレビューにしてください。** 色や写真が
> 「一色っぽい」「見えない」と思ったら、99%はこれが原因です。

   - `N`キーでパネルは閉じてOK

> ❗ここで詰まったら: Nパネルに `View` タブが見つからない → 3Dビューの中にマウスを置いて `N` を押しているか確認。

## 2. 地形（LiDAR）を読み込む（3分）

1. `File > Import > Wavefront (.obj)`
2. ファイル選択画面で右側に設定欄があります。**`Up Axis` が `Y`、`Forward Axis` が `-Z`** になっているか確認（通常は最初からこの値です）
3. `D:\00_Dev\ReplayViewer\tracktools-kit\fuji\terrain_lidar.obj` を選んで `Import`
   - 31MBあるので数秒〜十数秒待ちます
4. 緑がかった起伏のある地形が出れば成功。テンキー`7`で真上から見て、ホイールで全体が見えるまでズームアウト

> ❗地形が縦に立っている → Up Axis の設定ミス。`Ctrl+Z`で戻して手順2からやり直し。
> ❗何も見えない → ズームアウト不足 or Clip End 未設定（手順1-3）。

## 5. 道路を敷く — Track Tools の ROAD（10分）

### 5-1. Track Tools の部品（ノードグループ）をこのファイルに取り込む

1. `File > Append`（リンクではなく **Append** を選ぶ）
2. `D:\TrackTools\TrackTools_FULL_v2.1.1\TrackTools_FULL\TT_NodeGroups.blend` をダブルクリック
3. 中のフォルダ一覧から **`NodeTree`** をダブルクリック
4. `Ctrl`を押しながら **`ROAD`、`MARKINGS`、`RACING_KERB`** の3つをクリックして選択 → 右下 `Append`

> 💡 うまく `NodeTree` フォルダが見つからない/開けない場合は、代わりに
> **Asset Browser（画面下のタブ or Editor Type切替）**から Track Tools のアセットライブラリを
> 開き、`ROAD`/`MARKINGS`/`RACING_KERB` を3Dビューにドラッグ＆ドロップする方法もあります
> （Track Tools購入時に一緒に入る **Asset Browser Link Addon** が、これを
> やりやすくするための専用アドオンです）。どちらの方法でも、最終的に
> `bpy.data.node_groups` に `ROAD` 等が存在すればOKです。

### 5-2. 背骨の線に ROAD を付ける

0. **最初に必ず: 線の「太らせ（Bevel）」を切ります**。
   `centerline_ROAD_SPLINE` を選択 → プロパティ欄の**緑のカーブアイコン**
   （Object Data Properties）→ `Geometry` を展開 → `Bevel` → **`Depth` を `0` に**。
   > なぜ: 手順3のスクリプトは線を見やすくするため Bevel（太さ0.6m）を付けています。
   > Bevelが付いたままだと、カーブはROADに渡る前に**リボン状のメッシュに変換されて
   > しまい、ROADは「カーブが入ってこない」ため何もせず素通しします**。
   > 「設定は全部正しいのに road width をいくら変えても何も起きない」ときの原因はほぼこれです。
1. アウトライナー（右上の一覧）で **`centerline_ROAD_SPLINE`** をクリックして選択
2. 画面右下のプロパティ欄で **レンチのアイコン🔧**（モディファイアプロパティ）をクリック
3. `Add Modifier` をクリックすると、ここで**2パターン**あります（Blenderのバージョンや
   Appendの状態で変わります。どちらでも結果は同じです）:
   - **パターンA**: `Geometry Nodes` にマウスを乗せると**サブメニュー**が開き、そこに
     `ROAD` が名前で並んでいる → **直接クリック**すればOK（設定済みで追加される）
   - **パターンB**: `Geometry Nodes` をクリックすると**空のモディファイア**が1個追加される
     → モディファイアの上部にある**ノードグループ選択のドロップダウン**をクリックして
     一覧から **`ROAD`** を選ぶ
4. どちらの方法でも、選んだ直後に **設定項目がずらっと出ます**。**触るのはこの4つだけ**:

| 設定名 | 値 | 意味 |
|---|---|---|
| **reference terrain** | `terrain_lidar` を選ぶ | 高さをLiDAR地形に合わせる（＝高さ自動） |
| **Shrinkwrap** | ✅ オン | 上の機能のスイッチ |
| **road width** | まず `13` | 道幅（次の手順で写真に合わせて調整） |
| **material** | `asphalt` を選ぶ | 路面の見た目 |
| **Z offset** | `0.3` | 道路を地形より30cm浮かせる。`0`のままだと衛星写真付きの地形と同じ高さで重なり（Zファイティング）、**道路ができていても写真に隠れて見えません** |

5. 白い線が**幅のある道路（面）**に変わります。おめでとうございます、道が敷けました。
   （マテリアルプレビューにしていれば asphalt のグレーで、Solidモードのままなら
   薄灰色の近似色で見えます。どちらでも「線→面」に変わっていれば成功です。）

> ❗**線が面に変わらない**（相変わらず糸のような細い線のまま） →
>   これは表示モードの問題では**ありません**。以下を順に確認:
>   1. `centerline_ROAD_SPLINE` を選んだ状態でモディファイアを追加したか
>      （アウトライナーで別の物を選んでいないか再確認）
>   2. モディファイアのノードグループ欄が本当に `ROAD` になっているか（空/Newのままでないか）
>   3. **`reference terrain` に `terrain_lidar` が入っているか**（空欄のままだと
>      ROADは何もせず入力をそのまま素通りさせるため、線のまま変化しません）
>   4. `road width` が `0` になっていないか
>   5. **カーブの `Bevel Depth` が `0` になっているか**（手順0参照。0.6のままだと
>      設定が全部正しくても素通しになります）
> ❗**面にはなったが色が付かない** → 表示モードを確認（一番上の「超重要」を参照）。

## 6. 道幅を写真に合わせる（15分・ここが「あなたの仕事」）

1. テンキー`7`で真上 → ホイールでコースの一部（例:ホームストレート）にズーム
2. 衛星写真の**アスファルトの端**と、いま敷いた**道路の端**を見比べる
3. ROADモディファイアの **`road width`** の数字を、マウスで**左右にドラッグ**（またはクリックして数字入力）
4. 道路の端が写真のアスファルトの端に重なったらOK
   - 富士の目安: ストレートは**15m前後**、テクニカル区間は**11〜13m**
   - 全体を1つの幅で妥協するなら **14** 前後が無難
5. コースを一周ぐるっと見て回り、大きくズレている所がないか確認

> 💡 走行ライン（青・黄）が道路の中に収まっていることも確認。ドライバーは端まで使わないので、線が道の内側にあるのが正常です。
> 💡 高さは**何もしなくても**合っています。横から見ても道が地面に沿っているはず（Shrinkwrapの効果）。

### 6-b. 区間ごとに幅を変える（可変幅・検証済み）

`road width` は1つの値ですが、**カーブの点ごとの radius が幅の倍率として掛かります**
（実効幅 = `road width` × その点の radius。ヘッドレス検証で確認済み）。
これで「ストレートは広く、テクニカルは狭く」が正確に作り込めます。

1. `road width` は基準値のまま（例: `13`）
2. `centerline_ROAD_SPLINE` を選択して **`Tab`（編集モード）**
3. テンキー`7`の真上視点で、幅を変えたい区間の点を**ボックス選択**（`B`→ドラッグ）
4. **`Alt+S`** → マウス移動で太らせ/細らせ → クリックで確定
   - 数値で正確に入れるなら `Alt+S` の直後に数字をタイプ（例: `1.15` → 13×1.15≒15m）
   - いまの点の radius は `N`パネル > Item > Radius で確認・直接入力できる
5. `Tab` でオブジェクトモードに戻る → 道路の幅が区間ごとに変わっている
   - radius の変化は点間で滑らかに補間されるので、幅の変わり目は自然につながります

> ⚠️ 編集モードでは **`Alt+S`（radius）だけ**を使うこと。`G`（移動）や `S`（スケール）で
> 点を動かすと、実測由来の正確なライン・高さが壊れます。
> 💡 MARKINGS / RACING_KERB も同じカーブから作られるため、radius に追従して
> 白線・縁石が道路の端に付いてくる**はず**です（ROADで検証済み・他2つは目視確認を。
> 縁石の幅が太りすぎる等あればKERB側の width で微調整）。

## 7. 白線と縁石を足す（10分）

### 白線（MARKINGS）
1. `centerline_ROAD_SPLINE` を選択したまま、もう一度 `Add Modifier > Geometry Nodes`
2. ドロップダウンから **`MARKINGS`** を選ぶ
3. `material` に **`marking_white`** を指定
4. 線の種類の設定（middle line / border line など）がいくつかあります。**いじって画面を見る→気に入ったらOK**の感覚で大丈夫です（エッジの実線だけあれば十分レーシーに見えます）

### 縁石（RACING_KERB）
1. 同様に `Add Modifier > Geometry Nodes` → **`RACING_KERB`** を選ぶ
2. `Material` に **`kerb_redwhite`**（赤白）を指定
3. `width`（縁石の幅）や `kerb type` を触って好みに
   - 赤白の縞が細かすぎ/粗すぎな時は、`kerb_redwhite` マテリアルの Checker の `Scale` を変えると調整できます

> 💡 モディファイアは**上から順に効きます**。順番は ROAD → MARKINGS → RACING_KERB。

## 9. 書き出す（5分）

1. **書き出すものだけを選択**します: アウトライナーで `terrain_lidar` をクリック → `Ctrl`を押しながら `centerline_ROAD_SPLINE` をクリック（2つが選ばれた状態）
   - lap1〜3 や racingline_env、衛星などは**選ばない**
2. `File > Export > glTF 2.0 (.glb/.gltf)`
3. 右側の設定を確認:
   - Format: **glTF Binary (.glb)**
   - Include: **Selected Objects に✅**
   - Transform: **+Y Up に✅**（デフォルトのまま）
   - Data > Mesh: **Apply Modifiers に✅** ←重要（忘れると道路が消えます）
   - Material: **Export**（デフォルト）
4. 保存先とファイル名: `D:\00_Dev\ReplayViewer\public\data\tracks\fuji\scene.glb`（上書きOK。元のMOD版は `scene.mod.glb` に控えがあります）
5. `Export glTF 2.0` をクリック

> 💡 車の接地用ファイル（`road_ac_local.glb`）は**既に自動生成済みなので何もしなくてOK**です。幅を変えても、車が走るラインは中心±1mなので接地には影響しません。
